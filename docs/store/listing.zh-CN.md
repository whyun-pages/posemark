## 简短说明

```
类 Typora 的所见即所得 Markdown 编辑器：照常写 Markdown，标题、表格、公式、图表、图片就地渲染，只有光标所在行才显示标记。表格可直接按网格编辑，文件始终保存在你自己的磁盘上。
```

> 如认证对第三方名称“Typora”有异议，改为“实时预览（所见即所得）的 Markdown 编辑器……”。

## 说明

```
Posemark 是一款桌面 Markdown 编辑器，边写边渲染。你写的是普通 Markdown：标题就显示成标题，表格就显示成表格，数学公式和图表就地绘制，#、**、$$ 这些标记只在光标所在行重新出现。磁盘上的文件始终是标准 Markdown，可以直接配合 Git、静态站点生成器等任何 Markdown 工具使用。

实时预览编辑
- 标题、列表、引用、可点击勾选的任务列表、分隔线、粗体、斜体、删除线、高亮、上标和下标。
- 点进 GFM 表格即变成可编辑的网格：Tab / Shift+Tab 在单元格间移动，Enter 下移一行；右键菜单可插入、删除行列和设置对齐。每次按键都会写回 Markdown 源码。
- 围栏代码块语法高亮，可选行号与自动换行，编辑时依然保持高亮。
- KaTeX 行内与块级公式，支持 mhchem 化学式、physics 宏包常用命令、公式编号以及 \label / \ref 交叉引用。公式块打开为输入框，下方实时显示渲染结果。
- Mermaid 图表以及 sequence、flow 语法图表就地渲染并跟随编辑器主题，右键可另存为 SVG 或 PNG。
- GitHub 风格提示块（NOTE / TIP / WARNING 等）、脚注、可点击的 [TOC] 目录、带自动补全的 emoji 短代码、引用式链接和 YAML front matter。
- 源代码模式下以语法高亮显示原始 Markdown。

图片
- 拖入或粘贴图片，自动复制到文档的图片文件夹（默认 assets/）并插入链接；拖入视频或音频会插入播放器。
- 点击图片出现缩放框，拖动即可调整大小，尺寸写回 Markdown。
- 右键菜单可打开、在资源管理器中显示、复制、缩放、移动或删除图片，也可把网络图片下载到图片文件夹。
- 可选：通过你自己配置的 PicGo-Core、PicList 或自定义命令上传图片。

写作体验
- 智能标点、括号与 Markdown 标记自动配对；智能粘贴把网页、Word 中的富文本转换成 Markdown。
- 支持正则的查找替换、跳转到行、专注模式、打字机模式、缩放与全屏。
- 字数统计：字符、行、段落和预计阅读时间。

工作区
- 打开文件夹，在文件树里新建文件/文件夹、重命名、创建副本、拖放移动、移到回收站，并可撤销上一次文件操作。
- 快速打开、最近文件、固定文件夹、平铺文件列表视图和整个文件夹内搜索。
- 可折叠、可筛选的大纲面板。
- 其他程序对文件夹的修改会自动同步显示。
- 多窗口（每个窗口一个文档）、可选自动保存。
- 未保存的修改会自动备份为草稿，崩溃或强制关机也不会丢失，可从“文件”菜单恢复。

输出
- 导出为自包含的 HTML 或 PDF。
- 复制为 HTML 或 Markdown。
- 复制到微信公众号：只使用内联样式重建文档，公式与图表转换为图片，并提供实时预览调整排版样式。

主题
- 内置 Default、Night、Pixyll、Whitey、Newsprint 五套主题，可跟随 Windows 浅色/深色模式自动切换，也可以用自定义 CSS 覆盖或编写完整主题。

隐私
Posemark 只处理本地文件，没有账号、广告和遥测。只有当文档引用了网络图片、你要求下载图片，或你使用自己配置的图片上传工具时才会联网。

Posemark 免费并以 MIT 许可证开源。
```
