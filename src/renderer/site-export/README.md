# 网站导出

通过应用“文件 → 导出 → 网站…”打开。默认读取当前已打开的目录，也可以重新选择目录。内容面板支持排除文章与调整顺序，装帧面板支持书名、介绍、作者、颜色、纸张和字号设置，右侧使用最终阅读器进行预览。

导出会在选定位置新建网站子目录。已有同名目录时追加数字，不覆盖旧文件。导出读取磁盘上已保存的 Markdown，因此请先保存编辑中的文稿。名称以点号开头的目录与文件、符号链接及 node_modules 等排除目录不会被扫描；每次最多处理 2000 篇文章，单篇上限为 20 MB。

最终文件夹包含 index.html 和 assets。正文写入普通 JavaScript 数据文件，样式、阅读脚本、展示字体、公式字体、本地图片和附件一并打包，不依赖服务器、构建步骤、fetch 或 CDN。直接双击 index.html 即可阅读，将完整文件夹移动到其他位置也可正常打开。上传到静态托管平台使用同一份产物。

阅读器采用居中单栏正文与独立封面，点击“开始阅读”进入正文。顶部目录按钮展开可搜索、可独立滚动的侧栏，选择章节后收起；手机上目录占满阅读区域。设置面板集中提供按章阅读、连续滚动、字号和柔和白、暖纸色、浅绿、深色纸张。按章阅读支持键盘与滑动翻章。章节具有稳定 ID，站内 Markdown 链接转换成章节与标题锚点；文件夹路径作为分卷信息。浏览器前进与后退可以切换已访问的章节。

正文区域根据窗口可用高度自适应，顶部工具和底部章节导航始终可见。按章阅读在正文区内滚动当前文章，连续滚动模式在同一区域串联全部文章，并随阅读更新章节进度。窗口较矮时进一步缩小工具栏和正文留白，避免整页上下滚动才能找到导航。

网站不会自动下载网络图片和其他网络资源；遇到这些资源或未包含的章节链接时，会在导出前提示。本地资源缺失时停止导出并说明原因。第一版会清理原始 HTML 的脚本、事件属性、嵌入页面与外部样式，因此依赖这些内容的自定义交互不保留。Mermaid 和公式在导出前完成渲染。

勾选“记住这本书的设置”后，装帧、章节顺序与排除项保存在应用配置中，按源目录区分。设置不会写回源 Markdown 文件。导出页面和阅读器目前使用中文界面，菜单随应用语言切换。

资源复制与文件生成位于 src/main/website-export.js，窗口与 IPC 位于 src/main/website-window.js。ui.js 组织导出设置，render.js 复用现有 Markdown 渲染并处理发布资源，reader.html、reader.js、reader.css 构成离线阅读器。字体沿用已确认的书籍概念稿，许可保留在 assets/OFL.txt。

使用 pnpm test 验证现有功能与文件生成边界，使用 pnpm test:website 构建并验证实际导出界面、离线文件、资源移动、公式、图表、目录和手机布局，同时生成 tmp/website-demo-output 下的可阅读示例与 .impeccable/review/website-export 下的截图。
