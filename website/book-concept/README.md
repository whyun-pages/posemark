# Posemark 书本翻页网页版设计稿

直接打开本目录的 index.html，或从 website 目录启动静态服务器后访问 /book-concept/。此稿包含产品概览、专注书写、不止于文字和下载四组跨页，通过章节书签、底部按钮或键盘左右键切换；手机上采用单页并支持横向滑动。系统开启减少动态效果时，翻页会立即完成。

页面以现有 Posemark 官网内容为依据，复用 ../assets 下的品牌图标与实际功能截图。文档、隐私和下载入口保留为真实链接。除这些外链外，页面不依赖网络资源，不需要构建或安装依赖。

当前仅提供中文，用于评审视觉和交互，并非正式替换方案。视觉规范记录在 DESIGN.md，字体许可证在 assets/OFL.txt。正式上线前需要恢复现有中英双语内容，并进一步评估页面直达链接、搜索索引和长内容的阅读方式。

用户反馈后的版本以产品展示为主：首页直接显示编辑器截图，功能截图跨越双页，文案压缩在图上方。点击截图可查看原图，手机可在原图查看器内横向滚动。书签与翻页保留，封面装饰和长序言已撤去。
