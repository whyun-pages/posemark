# 网站导出交互设计稿

从本目录直接打开 index.html 即可预览，不需要安装依赖。也可以从仓库根目录启动静态服务器，访问 /website/export-concept/。

桌面静态预览见 [preview-desktop.png](preview-desktop.png)，手机完整页面见 [preview-mobile.png](preview-mobile.png)。交互效果以 index.html 为准。

这是 Posemark 新增“文件 → 导出 → 网站”的独立交互原型，没有接入桌面应用。左侧在内容、装帧和导出设置之间切换，右侧持续展示阅读网站效果。示例文章为本设计稿创作的虚构内容。

内容面板支持包含或排除文章、上下调整顺序以及点击预览章节。选择目录会由浏览器读取本地 Markdown 文本，仅用于预览，不上传文件；当前不解析完整 Markdown 格式、不呈现本地图片，也不展示真实分卷层级。正式功能仍需接入现有渲染与资源处理能力。

装帧设置可以实时修改书名、介绍、作者、封面颜色、纸张与字号。阅读预览支持章节翻页、连续阅读、桌面与手机视图、目录跳转、左右方向键及横向滑动，长章节在书页内部滚动。右上角的单一“目录”入口替代书边逐章标签，展开后可以搜索、滚动浏览全部章节，并标记正在阅读的位置。系统开启减少动态效果时不播放翻页动画。

导出设置及完成弹窗用于评审产品流程，不会生成文件，也不会持久化设置。完成弹窗明确标识演示状态，可进入放大的阅读预览，使用右上角按钮或 Esc 退出。正式导出需要另行实现目录编排、稳定链接、资源复制、配置保存及输出文件夹。

实际功能现已在应用“文件 → 导出 → 网站…”中接入。实现说明见 ../../src/renderer/site-export/README.md。本目录继续保留为可独立查看的设计稿。

视觉沿用现有应用的浅色工具界面与翻页概念稿的蓝色、纸张和书脊。独立样式与脚本只作用于本设计稿，不修改现有导出功能。复用的字体位于 ../book-concept/assets，许可见该目录 OFL.txt。
