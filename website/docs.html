使用文档Documentation

Posemark 是一款所见即所得的 Markdown 编辑器。这份文档介绍它的主要功能和设置。Posemark is a live-preview Markdown editor. This guide walks through its main features and settings.

安装Install

  • Windows：推荐从微软商店安装，可自动更新；也可以在 GitHub Releases 下载安装程序（.exe）或免安装版（.zip）。
  • macOS：下载对应芯片的 .dmg，把 Posemark 拖进“应用程序”。目前安装包未做公证，第一次打开时请右键点击应用并选择“打开”。
  • Linux：AppImage 加上可执行权限后直接运行；Debian / Ubuntu 可用 sudo apt install ./Posemark-*.deb 安装。

Windows 安装程序目前没有代码签名，SmartScreen 提示时点“更多信息 › 仍要运行”即可。

  • Windows: the Microsoft Store version updates itself. You can also grab the installer (.exe) or the portable .zip from GitHub Releases.
  • macOS: download the .dmg for your chip and drag Posemark into Applications. The build is not notarized yet, so the first time right-click the app and choose Open.
  • Linux: make the AppImage executable and run it, or install the deb with sudo apt install ./Posemark-*.deb.

The Windows installer is not code-signed yet; when SmartScreen warns, choose More info › Run anyway.

快速上手Getting started

用 文件 › 打开文件夹（Ctrl+Shift+O）打开你存放笔记的文件夹，左侧就是文件树；双击 .md 文件也会直接用 Posemark 打开。

直接输入 Markdown 即可：输入 # 标题 回车，它立刻就是一个标题。光标所在的那一行会显示原始标记，离开后恢复排版效果。

  • Ctrl+/：在实时预览和源代码模式之间切换。
  • Ctrl+P：按文件名快速打开；Ctrl+Shift+F：在整个文件夹中搜索。
  • 侧边栏有 文件、大纲、搜索 三个面板；Ctrl+Shift+L 显示或隐藏侧边栏。
  • 一个窗口编辑一个文档，Ctrl+Shift+N 新建窗口，Ctrl+Tab 在窗口间切换。

Use File › Open Folder (Ctrl+Shift+O) to open the folder that holds your notes; it appears as a file tree on the left. Double-clicking a .md file opens it in Posemark too.

Just type Markdown: # Title plus Enter is a heading straight away. The line your caret is on shows its raw markers; move away and it is typeset again.

  • Ctrl+/ switches between live preview and source code mode.
  • Ctrl+P opens a file by name; Ctrl+Shift+F searches the whole folder.
  • The sidebar has Files, Outline and Search panels; Ctrl+Shift+L shows or hides it.
  • One document per window: Ctrl+Shift+N opens another, Ctrl+Tab cycles through them.

文件与目录Files and folders

文件面板以文件夹、Markdown 文档和其他文件的图标区分内容类型。点击文件夹所在行展开或收起，展开后的层级线帮助你辨认归属；点击文件打开文稿，文件名过长时会省略显示，悬停可查看完整名称。目录顶部的“折叠所有文件夹”按钮可以一次收起全部层级。

右键文件或文件夹，可以新建、重命名、创建副本、移动到回收站或在系统文件管理器中显示。选中条目后按 F2 重命名；把条目拖到另一个文件夹可以移动它，拖到文件树的空白区域则移到当前根目录。“撤销上次文件操作”支持撤回重命名、移动、新建和创建副本；已经删除的文件需要从系统回收站恢复。

文件树获得焦点时，上下方向键选择条目，左右方向键展开、收起或返回上一级，Enter 打开文件。顶部的列表按钮在文件树与按修改时间从新到旧排列的文章列表之间切换；“更多”菜单提供自然排序、按名称或日期排序、降序，以及显示隐藏文件和所有文件类型的开关。非 Markdown 文件使用系统默认应用打开。

常用目录可以通过“更多”菜单固定，在“打开最近文件”和快速打开中更容易找到。拖动侧栏右边缘可调整宽度，应用会记住这一设置。

The Files panel distinguishes folders, Markdown documents and other files with icons. Click a folder row to expand or collapse it; guide lines show its nesting. Click a document to open it. Long names are shortened, with the full name available on hover. The Collapse all folders button closes every expanded level.

Right-click an item to create, rename, duplicate, move it to the trash or reveal it in your file manager. Press F2 to rename the selected item. Drag it onto a folder to move it, or onto empty tree space to move it to the current root. Undo Last File Operation reverses renaming, moving, creating and duplicating. Restore deleted files from your system's trash.

With the tree focused, use Up and Down to select, Left and Right to collapse, expand or move through the hierarchy, and Enter to open. The list button switches between the tree and a flat list of articles, newest modified first. The more menu offers natural, name and date sorting, descending order, hidden files and all file types. Non-Markdown files open in their default application.

Pin frequently used folders from the more menu to find them in Open Recent and Quick Open. Drag the sidebar's right edge to resize it; the width is remembered.

编辑Editing

文字与段落

支持加粗、斜体、删除线、==高亮==、H~2~O 下标、X^2^ 上标、行内代码和链接。“段落”和“格式”菜单里的命令都有快捷键，例如 Ctrl+1～6 设置标题级别。

表格

点击表格就进入网格编辑：Tab 到下一格，Enter 到下一行，在最后一格按 Tab 会新增一行。右键单元格可以插入、删除行列，以及设置对齐方式。

代码块

用 ```语言 开始一个代码块，会按语言高亮。光标进入代码块后显示源码，依然保持高亮。

预览中的代码块顶部显示语言名称；点击右上角“复制”可复制整段代码，成功后会显示“已复制”。显示行号与自动换行可在 偏好设置 › Markdown 中调整。

更多语法

  • 任务列表 - [ ]，点击复选框即可勾选。
  • GitHub 风格提示块：> [!NOTE]、[!TIP]、[!WARNING] 等。
  • 单独一行写 [TOC] 生成目录；[^1] 写脚注；:smile: 输入表情。

粘贴

从网页、Word 等处复制的富文本会自动转换成 Markdown；Ctrl+Shift+V 始终粘贴纯文本。

Text and paragraphs

Bold, italic, strikethrough, ==highlight==, H~2~O subscript, X^2^ superscript, inline code and links all work. Everything in the Paragraph and Format menus has a shortcut — Ctrl+1…6 set the heading level, for example.

Tables

Click a table to edit it as a grid: Tab moves to the next cell, Enter to the next row, and Tab in the last cell adds a row. Right-click a cell to insert or delete rows and columns, or to set the alignment.

Code blocks

Start a block with ```language to get highlighting. With the caret inside, you see the source — still highlighted.

The preview header shows the language. Copy at the top right copies the block's code and confirms success with Copied. Line numbers and wrapping can be changed in Preferences › Markdown.

More syntax

  • Task lists with - [ ]; click a box to tick it.
  • GitHub-style alerts: > [!NOTE], [!TIP], [!WARNING] and friends.
  • [TOC] on its own line builds a table of contents; [^1] adds a footnote; :smile: inserts an emoji.

Pasting

Rich text from web pages, Word and the like is converted to Markdown when you paste; Ctrl+Shift+V always pastes plain text.

图片Images

  • 把图片拖进编辑区，或直接粘贴截图，图片会复制到文档旁的 assets/ 文件夹，并插入 ![](assets/xxx.png)。
  • 点击图片出现缩放框，拖动右下角调整大小，宽度会写成 ![alt|320](pic.png)。
  • 右键图片可以打开、复制、调整缩放比例、移动到其他文件夹、下载网络图片或上传到图床。
  • 在 偏好设置 › 图片 里可以改插入方式（复制 / 保留原路径 / 直接上传）、图片文件夹，以及配置 PicGo-Core、PicList 或自定义命令作为上传服务。
  • front matter 中的 typora-copy-images-to 和 typora-root-url 与 Typora 兼容。
  • Drop an image onto the editor, or paste a screenshot: the file is copied into an assets/ folder next to the document and ![](assets/xxx.png) is inserted.
  • Click an image for a resize frame; dragging the corner writes the width as ![alt|320](pic.png).
  • Right-click an image to open, copy, zoom, move it to another folder, download a remote image or upload it.
  • Preferences › Images sets the insert policy (copy / keep the path / upload), the image folder, and an uploader: PicGo-Core, PicList or a custom command.
  • typora-copy-images-to and typora-root-url in the front matter work as in Typora.

公式Math

行内公式用 $…$ 或 \(…\)，独立公式用 $$…$$、\[…\] 或 ```math 代码块，由 KaTeX 渲染。Ctrl+Shift+M 插入公式块，编辑时下方实时显示结果。

  • 编号：偏好设置 › Markdown › 公式 可选择不编号、AMS 风格或全部编号；\label{eq:x} 加 \eqref{eq:x} 引用编号。
  • 内置 mhchem 化学式 \ce{H2O}，以及 physics 宏包的常用命令（\dv、\abs、\ket 等）。

Inline math with $…$ or \(…\); display math with $$…$$, \[…\] or a ```math fence, rendered by KaTeX. Ctrl+Shift+M inserts a math block that shows its result live underneath.

  • Numbering: Preferences › Markdown › Math offers none, AMS style or every equation; \label{eq:x} with \eqref{eq:x} refers to the number.
  • mhchem (\ce{H2O}) and the common physics-package commands (\dv, \abs, \ket…) are built in.

图表Diagrams

```mermaid 代码块会绘制成 Mermaid 图表，停止输入片刻后自动重绘，语法错误会显示在预览中而不会覆盖你的文字。```sequence（js-sequence-diagrams）和 ```flow（flowchart.js）语法也能识别。

图表配色跟随编辑器主题，也可以在 偏好设置 › Markdown › 图表 中调整。右键图表可另存为 SVG、PNG 或复制。

图表顶部的“预览 / 源代码”按钮切换图形与 Mermaid 源码视图；切换视图不会改写文稿。右上角的展开按钮可放大图表显示区域，再点一次恢复。“更多操作”菜单提供另存为 SVG、另存为 PNG、复制为 PNG 和复制 SVG 代码，右键图表也能打开同一组操作。

A ```mermaid fence is drawn as a Mermaid diagram and redrawn shortly after you stop typing; a syntax error shows in the preview instead of replacing your text. ```sequence (js-sequence-diagrams) and ```flow (flowchart.js) syntax work too.

Diagrams follow the editor theme, with options in Preferences › Markdown › Diagrams. Right-click a diagram to save it as SVG or PNG, or copy it.

Preview and Source in the header switch between the drawing and its Mermaid source without changing the document. Expand enlarges the diagram area; press it again to restore the view. More actions offers Save as SVG, Save as PNG, Copy as PNG and Copy SVG Code. The same actions are available by right-clicking the diagram.

导出Export

文件 › 导出 中可选：

  • HTML：单个自包含文件，主题样式、公式字体、图表都内嵌在内，可选附带可折叠大纲。
  • HTML（无样式）：只有 HTML 标记，方便粘贴到其他网站或模板。
  • PDF：可设置纸张（A3/A4/A5/B5/Letter 等或自定义尺寸）、横向、边距、页眉页脚、一级标题前分页。
  • 图片 (PNG)：整篇文档渲染为一张长图，宽度可调。
  • 网站…：将一个目录中的多篇 Markdown 编排成可离线阅读的网站，详见导出为网站。
  • 使用上次设置导出（Ctrl+Alt+E）：按上次的格式直接导出到上次的文件夹，不弹对话框。

页眉页脚用 左 | 中 | 右 分成三栏，可使用变量：${title}、${author}、${today}、${pageNo}、${pageCount}，以及 front matter 中的任意键。例如页脚 ${title} | | ${pageNo} / ${pageCount}。

front matter 里的 title、author、description、keywords 会写入 PDF 的文档属性。导出主题、默认导出文件夹、导出后是否打开文件都在 偏好设置 › 导出 中设置。

File › Export offers:

  • HTML: one self-contained file with the theme, math fonts and diagrams inlined, optionally with a collapsible outline.
  • HTML (without styles): bare markup, for pasting into another site or template.
  • PDF: paper size (A3/A4/A5/B5/Letter… or a custom size), landscape, margins, header and footer, a page break before every level-1 heading.
  • Image (PNG): the whole document as one long picture at an adjustable width.
  • Website…: arrange Markdown files from a folder into an offline reading website; see Export a website.
  • Export with Previous (Ctrl+Alt+E): the last format into the last folder, no dialog.

Headers and footers split into left | center | right and accept ${title}, ${author}, ${today}, ${pageNo}, ${pageCount} and any front matter key — e.g. a footer of ${title} | | ${pageNo} / ${pageCount}.

title, author, description and keywords from the front matter go into the PDF's document properties. The export theme, default folder and what happens after exporting live in Preferences › Export.

导出为网站Export a website

网站导出从 Posemark 0.3.0 开始提供。若已安装版本还没有“网站…”菜单，请升级到 0.3.0 或更新版本。网站导出页和生成的阅读器目前使用中文界面，菜单入口随应用语言切换。

先保存要收录的文章，再打开 文件 › 导出 › 网站…。导出页默认读取当前打开的文件夹，也可以点击“选择目录”重新选择。它读取的是磁盘上已保存的 Markdown，不包含编辑器中尚未保存的修改；更新原文后，点击“重新读取目录”刷新。

整理内容与装帧

“内容”页列出目录与子目录中的文章。勾选需要的章节，悬停或聚焦章节行后用上下按钮调整顺序，点击标题预览正文。文件夹路径作为分卷信息保留；章节名称依次采用 front matter 的 title、正文第一个一级标题，或文件名。

在“装帧”页填写书名、一句介绍和作者，选择封面颜色、纸张及正文字号。右侧使用实际阅读器预览，支持切换按章或连续阅读、桌面或手机视图，也可以放大查看。只切换预览不会改变最终的默认阅读方式；默认值在“导出”页设置。

生成网站文件夹

“导出”页填写网站文件夹名称，例如 my-notes，使用英文字母、数字、短横线或下划线，长度不超过 60 个字符。选择默认按章或连续阅读，并按需保留“记住这本书的设置”。点击“导出网站”后选择保存位置，应用会新建一个子文件夹；同名文件夹已存在时追加数字，不覆盖旧内容。

记住的装帧、章节顺序和排除项按源目录分别保存在应用配置中，不会写回 Markdown。此功能独立于单篇文档的 HTML、PDF 导出设置，也不属于“使用上次设置导出”的重复导出流程。

资源与范围

本地图片、附件、样式、阅读脚本和字体随网站复制，公式与 Mermaid 图表在导出前完成渲染。已收录 Markdown 文件之间的链接会转换为章节或标题跳转；被排除章节的链接会提示。网络图片等资源不会自动下载，导出时会提示仍需联网；本地资源缺失则停止导出，请修复引用或排除相关章节。

扫描跳过以点号开头的文件与目录、符号链接，以及 node_modules 等排除目录；最多处理 2000 篇文章，单篇上限为 20 MB。原始 HTML 中的脚本、嵌入页面、事件处理和外部样式不会保留，因此依赖这些内容的自定义交互需要重新评估。

Website export is available starting with Posemark 0.3.0. If your installed version has no Website… menu, upgrade to 0.3.0 or later. The export panel and generated reader currently use Chinese; the menu entry follows the app language.

Save the articles first, then open File › Export › Website…. The panel starts with your current folder; 选择目录 (Choose folder) selects another. It reads saved Markdown from disk, not unsaved editor changes. Use 重新读取目录 (Reload folder) after changing the source files.

Arrange chapters and appearance

内容 (Content) lists articles in the folder and its subfolders. Select the chapters to include, hover or focus a chapter row to move it up or down, and click its title to preview it. Folder paths supply group labels. Chapter titles use the front matter title, then the first level-one heading, then the filename.

装帧 (Appearance) sets the book title, introduction, author, cover colour, paper and text size. The real reader on the right previews chapter or continuous reading, desktop and phone views, and an expanded view. Previewing a mode does not change the exported default; set that in 导出 (Export).

Generate the website folder

In Export, name the output folder, for example my-notes, using up to 60 letters, digits, hyphens or underscores. Choose the default reading mode and whether to remember this book's settings. Click 导出网站 (Export website) and choose a destination. A new subfolder is created; a number is added if its name already exists, preserving previous exports.

Remembered appearance, order and excluded chapters are stored per source folder in the app configuration, without rewriting your Markdown. Website export has its own settings and is separate from single-document HTML/PDF export and Export with Previous.

Resources and limits

Local images, attachments, styles, reader scripts and fonts are copied with the website. Equations and Mermaid diagrams are rendered before export. Links between included Markdown files become chapter or heading links; links to excluded chapters produce a warning. Remote resources are not downloaded automatically and still require a connection. Missing local resources stop the export; repair the reference or exclude the chapter.

Scanning skips dot-prefixed files and folders, symbolic links and excluded directories such as node_modules. There is a limit of 2,000 articles and 20 MB per file. Scripts, embedded pages, event handlers and external styles in raw HTML are removed, so custom interactions depending on them are not preserved.

离线阅读与分享Offline reading and sharing

导出完成后可以直接打开阅读网站，或在文件夹中双击 index.html。产物由 index.html 和 assets/ 组成，不需要服务器或额外构建。分享、移动或上传时请携带整个文件夹；只发送 HTML 文件会缺少正文、图片与样式。上传到静态托管平台后，也可通过网址访问。

封面上的“开始阅读”进入正文。顶部“目录”展开可搜索的章节侧栏，选择章节后收起，手机上目录覆盖阅读区域。正文居中单栏显示，长章节在正文区内滚动；按章模式下可用底部按钮、左右方向键或横向滑动切换章节，浏览器的前进、后退也能返回访问过的章节。

阅读器的“设置”可以切换按章阅读或连续滚动，调整字号，并选择柔和白、暖纸色、浅绿或深色纸张。阅读器会随窗口高度调整正文区域，较矮窗口会压缩工具栏与留白。外部网页链接、未打包的网络图片仍需联网。

After exporting, open the website from the completion panel or double-click index.html. The output contains index.html and assets/, with no server or build step required. Move, send or upload the entire folder; the HTML file alone is missing its content, images and styles. The same folder can be published on static hosting.

开始阅读 (Start reading) opens the first chapter. 目录 (Contents) opens a searchable chapter sidebar that closes after selection; on phones it fills the reading area. Long chapters scroll within a centred single-column reading surface. Chapter mode supports bottom navigation, Left/Right keys and horizontal swipes. Browser Back and Forward revisit chapters.

设置 (Settings) switches between chapter and continuous reading, changes text size and offers soft white, warm paper, pale green and dark paper. The reading area adapts to the window height, with compact toolbars and spacing in shorter windows. External web links and remote images that were not bundled still need a connection.

复制到公众号Copy for WeChat

公众号编辑器会丢弃所有样式表，普通复制粘贴过去只剩光秃秃的文字。文件 › 导出 › 复制到微信公众号（Ctrl+Alt+C）会把排版写成行内样式放进剪贴板，直接粘贴到公众号后台即可：

  • 代码保留高亮颜色，表格带边框和表头底色。
  • 本地图片内嵌进内容；公式和 Mermaid 图表自动转成图片。
  • 公众号里链接不能点击，所以每个链接会加上编号，并在文末列出“参考链接”。

在 偏好设置 › 公众号 中可以调整配色、强调色、二级标题样式、字号、行高、字间距、段间距、首行缩进等，右侧实时预览粘贴后的效果。

WeChat's article editor throws away every stylesheet, so an ordinary copy arrives as bare text. File › Export › Copy for WeChat (Ctrl+Alt+C) puts the formatting on the clipboard as inline styles — paste it straight into the editor:

  • Code keeps its highlight colours; tables get borders and a shaded header.
  • Local images are embedded; formulas and Mermaid diagrams become images.
  • Links cannot be clicked in WeChat, so each gets a number and the URLs are listed at the end.

Preferences › WeChat tunes the colour theme, accent colour, heading style, font size, line height, spacing and first-line indent, with a live preview of the pasted result.

主题与自定义 CSSThemes and custom CSS

内置 Default、Night、Pixyll、Whitey、Newsprint 五套主题，在“主题”菜单中切换。偏好设置 › 外观 中开启“跟随系统深色模式”后，可以分别指定浅色和深色主题。

主题 › 打开主题文件夹 可以放入自己的样式：

  • base.user.css：追加到所有主题；
  • <主题名>.user.css：只追加到该主题，如 night.user.css；
  • 完整的 <名字>.css 会作为新主题出现在菜单中（文件开头写 /* dark */ 标记为深色主题）。

Default, Night, Pixyll, Whitey and Newsprint ship built in; switch from the Themes menu. With Preferences › Appearance › Follow the system dark mode you choose one theme for light mode and one for dark.

Themes › Open Theme Folder takes your own styles:

  • base.user.css is added to every theme;
  • <theme>.user.css to that theme only, e.g. night.user.css;
  • a whole <name>.css becomes a theme of its own (start it with /* dark */ to mark it dark).

设置与草稿Settings and drafts

  • 界面语言：偏好设置 › 通用 › 语言，可选跟随系统、English 或简体中文，切换后立即生效。
  • 自动保存：偏好设置 › 通用 › 保存。
  • 未保存草稿：有未保存修改时内容会自动备份，意外关闭或断电后，用 文件 › 恢复未保存的草稿 找回。
  • 启动行为：新建空白文档、恢复上次的文件夹、恢复上次的文件，或打开固定文件夹。
  • 智能标点、自动补全括号与 Markdown 符号、拼写检查等都可以在 偏好设置 › 编辑器 中开关。
  • Interface language: Preferences › General › Language — follow the system, English or Simplified Chinese; switching applies at once.
  • Auto save: Preferences › General › Saving.
  • Unsaved drafts: unsaved edits are backed up as you type; after a crash or power cut, File › Recover Unsaved Drafts brings them back.
  • On launch: a new document, the last folder, the last file, or a fixed folder.
  • Smart punctuation, auto-pairing of brackets and Markdown markers, and spell check are switches in Preferences › Editor.

常见问题FAQ

Posemark 会上传我的文档吗？

不会。Posemark 没有账号、没有遥测，文档只保存在你自己的电脑上。只有在你配置了图床上传、或文档里引用了网络图片时才会联网，详见隐私政策。

和 Typora 的文件兼容吗？

兼容。Posemark 读写的都是普通 Markdown 文件，也识别 Typora 的 typora-copy-images-to、typora-root-url、图片缩放写法和 [TOC]。

导出的网站必须部署到服务器吗？

不需要。保持 index.html 与 assets/ 在同一文件夹，双击 HTML 即可阅读。完整打包的本地内容可离线使用；网页链接和未下载的网络资源仍需联网，详见离线阅读与分享。

遇到问题怎么反馈？

请在 GitHub Issues 提交，附上系统版本和复现步骤会很有帮助。

Does Posemark upload my documents?

No. There is no account and no telemetry; your documents stay on your computer. The app only goes online for images your document links to, or for uploads you set up yourself — see the privacy policy.

Is it compatible with Typora files?

Yes. Posemark reads and writes plain Markdown and understands Typora's typora-copy-images-to, typora-root-url, image sizing and [TOC].

Does an exported website need a server?

No. Keep index.html and assets/ together and double-click the HTML file. Bundled local content works offline; external links and remote resources still need a connection. See Offline reading and sharing.

Where do I report a problem?

Open an issue on GitHub; your OS version and the steps to reproduce help a lot.
