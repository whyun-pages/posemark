# Make room for your words

Capture an idea in **Markdown** and see a finished document as you write.

## Start with a few words

Keep notes, drafts and references in local folders. Headings, lists and tables render in place, with Markdown markers on the line you edit.

| What you write | What you can do |
| --- | --- |
| Everyday notes | Organize folders and find any article |
| Technical docs | Add equations, diagrams and code |
| Something to share | Export PDF, HTML or a long image |

## Give an idea its shape

```typescript
const note = {
  title: "A good day to write",
  format: "Markdown"
};
```

## Write first. Share when ready.

Keep your Markdown files and choose the right format for your readers.
