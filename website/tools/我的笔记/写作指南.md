# 让文字，自然成篇

用 **Markdown** 记录想法，在写下的那一刻，看见排好版的文章。

## 从一段文字开始

打开本地文件夹，让笔记、资料和草稿各归其位。标题、列表和表格会直接呈现，光标所在行保留熟悉的 Markdown 标记。

| 写作场景 | 你可以做什么 |
| --- | --- |
| 日常笔记 | 整理文件夹，快速找到文章 |
| 技术文档 | 插入公式、图表与代码 |
| 内容分享 | 导出 PDF、网页或长图 |

## 把想法写清楚

```typescript
const note = {
  title: "今天，开始写作",
  format: "Markdown"
};
```

## 写好之后，再出发

保留自己的 Markdown 文件，选择适合的方式分享内容。
